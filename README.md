# Factory_dashboard

## Описание проекта

Это веб-приложение c информацией о производственных установках завода. На текущий момент реализованы три страницы, с полной информацией только для установки АТ-ВБ.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/Automation-service-summer-practice-2025/Factory_dashboard.git
cd factory_dashboard
```

### 2. Сборка и запуск контейнера

```bash
docker-compose up -d --build
```

Приложение будет доступно по адресу: http://localhost:8080

### 3. Остановка приложения

```bash
docker-compose down
```
